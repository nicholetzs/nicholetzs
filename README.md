### About Me

I am currently developing **Orbitalia**, my undergraduate thesis project: a collaborative platform for standardization and automated classification of light curves observed by amateur astronomers.

---

### 🚀 Current Project

**Orbitalia** *(Undergraduate Thesis – 2026)*  
Collaborative platform for preprocessing and automated classification of light curves from amateur astronomers.

- Pipeline for ingestion, cleaning and standardization of photometric data  
- Machine Learning models for classifying transit signals vs false positives  
- Evaluation of how data standardization impacts classification performance  
- Integration of collaborative observations with automated analysis

> Goal: support citizen science contributions in exoplanet research by making heterogeneous amateur data more usable.
